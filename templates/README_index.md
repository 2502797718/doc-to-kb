## 查什么去哪本

| 要查什么 | 去哪本 | 章节 |
|---|---|---|
| 引脚支持哪些复用功能 | **DS** | 引脚复用清单（按端口分表） |
| MUX 编号是几 | **RM** | IOMUX 功能输入/输出（表6-1/6-2/6-3…） |
| 外设寄存器位域 | **RM** | 各外设章末尾「寄存器描述」 |
| IRQn 数值 / 时钟宏 | **固件库** | `at32f423.h`（IRQn 枚举）/ `at32f423_crm.h`（时钟宏） |
| 已知芯片缺陷 | **Errata** | 全文 |

> ⚠ **MUX 编号不可按功能列表顺序推测**。AT32 的 MUX 号按外设功能类别固定分配，
> 与数据手册功能清单的书写顺序无关，必须查 RM 表。
